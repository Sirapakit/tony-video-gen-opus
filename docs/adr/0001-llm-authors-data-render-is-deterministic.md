# An LLM writes the Story and Storyboard; the Render is deterministic

The LLM is used only to produce editable data (Story, Storyboard). Render turns that data into pixels and sound with fixed code, so a hundred videos cost no LLM tokens and a Render is deterministic **for immutable inputs**: the saved Story, Preset, cached narration audio and assets, and pinned engine, Style pack and tool versions (browser, ffmpeg, fonts). That pin set is recorded in each Job's manifest; changing any of it, or losing the audio cache, forfeits the guarantee. The LLM step and fresh TTS are not deterministic. The alternative, an agent writing drawing code per film (as lemo-opuscar does, 30-60 min and many tokens each), is kept only as a separate, clearly labelled agent-driven kind of Style pack that makes no reproducibility claim.
